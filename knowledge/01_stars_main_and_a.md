# Zi Wei Dou Shu Star Reference
Primary framework: Zhang Sheng-Shu / Technology Zi Wei.
Use this file for star meanings. Do not treat a star as an isolated verdict.

## Star Weight Levels
- S ★★★★★ 核心結構，直接決定命盤主要性格、人生格局與宮位主題（14顆主星）
- A ★★★★☆ 強力修正器，可明顯改變主星與宮位的表現；部分煞曜可形成強烈事件訊號
- B ★★★☆☆ 中度修正與具體化，通常不能單獨推翻主結構，但在特定宮位／問題可很有辨識度
- C ★★☆☆☆ 輔助性訊號，主要用於補充狀態、階段、細節與事件背景
- D ★☆☆☆☆ 低權重背景訊號，主要用於特定時間層的事件修飾，不應單獨影響主要結論


## 紫微
- level: S
- core: 領導慾、主導、管理、自尊、責任
- positive: 整合資源、承擔責任、建立秩序
- risk: 剛愎、控制、過度自尊
- archetype: 領導型
