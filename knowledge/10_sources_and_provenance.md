# Source Provenance and Rule Classification

## Purpose
This file tells the GPT how to distinguish published material from structured synthesis.

## Labels

### ZHANG_SHENG_SHU
Use when the rule or description is directly supported by public material attributed to Zhang Sheng-Shu / Technology Zi Wei.

### TRADITIONAL
Use for supplementary mainstream/traditional Zi Wei material when needed.

### OTHER_SCHOOL
Use for a rule that belongs to another identifiable school. Do not silently merge it into the primary method.

### INFERENCE
Use for a structured synthesis created for this GPT from one or more source principles.
Inference is useful for reasoning but must never be described as a verbatim published Zhang Sheng-Shu rule.

## Current Inference Matrices

### 14 Main Stars × 12 Palaces
The 168-cell matrix is a structured compositional baseline.
It is based on the public principle that the same Main Star changes expression according to palace context.
It is NOT claimed to be an official 168-cell Zhang Sheng-Shu table.

### Source Star × Four Transformations
The 56-cell matrix is a structured compositional baseline.
It models how a transformation modifies the source star's existing mechanism.
It is NOT claimed to be a verbatim proprietary Zhang Sheng-Shu table.

### Four Transformations × 12 Palaces
The 48-cell matrix is a structured compositional baseline.
It is based on public transformation semantics and the principle that effects differ by palace.
It is NOT claimed to be a verbatim proprietary Zhang Sheng-Shu table.

## Zhang-Specific Dual-Star Catalog
