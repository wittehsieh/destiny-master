# Four Transformations

## 化祿
- axis: resource / opportunity / attraction
- core: 資源與機會較容易聚集

## 化權
- axis: authority / responsibility / execution
- core: 主動性、責任與主導權提高

## 化科
- axis: recognition / reputation / knowledge
- core: 專業、名聲與被看見的機會增加

## 化忌
- axis: friction / attachment / adjustment
- core: 問題與牽掛成為需要反覆處理的焦點

# Source Star × Transformation

Each entry's `mechanism`, `positive`, and `risk` are written specifically for that star-transformation combination -- do not assume a star's positive/risk reads the same across 化祿/化權/化科/化忌, or that a transformation's positive/risk reads the same across different stars.

## 紫微 + 化祿
- mechanism: 統御與資源整合更容易得到支持，容易因位置、信任或整合能力取得更多可運用資源。
- positive: 統御與資源整合更容易得到支持，容易因位置、信任或整合能力取得更多可運用資源。成熟時，這些資源會進一步鞏固你在群體中的位置，讓「被需要」與「被信任」變成長期資本，而不只是短期進帳。
- risk: 若太享受資源集中在自己手上的感覺，容易擴大權責與開支，最後管理成本超過真正收益。
- source_class: INFERENCE

- positive: 改革衝動轉成強烈的執行與重建能力，容易主導制度或方向變革。成熟時，推動變革的力量會搭配足夠的溝通與承接規劃，讓新制度真的能落地，而不只是一次次的推翻重來。
- risk: 改革權力變大時容易一次推翻太多制度，組織若沒有承接能力，變革會先造成混亂。

- source_class: INFERENCE

- positive: 破舊立新的特質容易失去節制，可能因急著改變而反覆推翻尚未成熟的成果。若能在改變之前先盤點值得保留的部分，反而能讓重建的成果真正穩定下來，不被下一波衝動推翻。
- risk: 不滿容易累積到想一次全部推翻，若沒有保留可用資源，重建的代價會比原問題更大。
- source_class: INFERENCE
